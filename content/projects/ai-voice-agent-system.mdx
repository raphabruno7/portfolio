# AI Voice Agent System

A voice agent that answers inbound and outbound calls, qualifies leads in natural conversation, books meetings straight onto the calendar, and hands off to a human with an attended transfer — so a caller is never dropped into voicemail. Multilingual: Portuguese, English, Spanish and French.

Built across six voice stacks in parallel to compare pipeline architectures — speech-to-speech against cascaded STT→LLM→TTS — and instrumented with per-turn latency measurement and daily health checks across ten external services.
