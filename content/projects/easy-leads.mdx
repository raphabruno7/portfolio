# Easy Leads AI

<img src="/project-easy-leads.gif" alt="Easy Leads AI — searching for restaurants in Lisbon" style={{borderRadius: '12px', width: '100%', maxWidth: '480px', display: 'block', margin: '0 auto 2rem'}} />

An AI-powered lead prospecting tool built for local businesses in Peniche — surf schools, restaurants, and real estate.

### Discovery

Local businesses in coastal towns like Peniche rely almost entirely on word of mouth and have no structured system for finding new customers or understanding their digital presence. There was a clear opportunity to build a tool that could automatically map the landscape — who is active, who is not, and who is most likely to benefit from AI-powered automation.

### Strategy

Rather than building a generic CRM import tool, the focus was on scoring each lead's readiness for AI agent adoption. The system scrapes Instagram profile metrics (followers, engagement, post frequency) and cross-references with Google Maps data to assess visibility. A scoring algorithm ranks businesses by their automation potential — so outreach effort goes where it matters most. Output feeds directly into Arcus CRM.

### Execution

- Built Python scrapers using Apify to pull Instagram profile data and phone numbers via Google Search
- Implemented an activity scoring algorithm based on follower count, posting frequency, and engagement rate
- Generated structured Excel outputs and visual HTML dashboards per niche (surf schools, restaurants, real estate)
- Designed a hub interface (Easy Leads AI) to navigate between niche dashboards, deployed as a static site
